# KADR Studio — готовые версии

Здесь лежат только готовые установщики KADR Studio для Windows и macOS и файл `latest.json`, по которому программа
сама находит обновления. Исходного кода здесь нет.

Обновляться вручную не нужно: KADR Studio раз в день проверяет новую версию и предлагает «Обновить».
Каждая версия подписана — программа ставит только файлы с правильной подписью.
